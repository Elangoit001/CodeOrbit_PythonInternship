## Setup Instructions
1. Install Python 3 from https://www.python.org/downloads/
2. Clone this repository:
```bash
   git clone https://github.com/Elangoit001/CodeOrbit_PythonInternship.git
   cd CodeOrbit_PythonInternship
```
3. Run any project:
```bash
   python calculator.py
   python todo_app.py
   python number_guessing_game.py
```

## Features
- **Calculator:** add, subtract, multiply, divide; handles invalid input and division by zero using try/except.
- **To-Do App:** add, view (numbered) and remove tasks; tasks are saved to `tasks.txt`.
- **Guessing Game:** too high / too low hints, attempt counter, multiple rounds.
